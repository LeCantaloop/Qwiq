### W2.13 - SBOM Generation (Dual Pipeline) (HIGH)
**Status**: ✅ Complete

**Objective**: Generate Software Bill of Materials in BOTH build and release pipelines.

**What was done**:
- Added SBOM validation generation in main.yml (build pipeline)
- Added authoritative SBOM generation in release.yml (release pipeline)
- Using microsoft/sbom-tool@v2 for SPDX 2.3 format
- Configured SBOM attachment to GitHub Releases
- Created comprehensive SBOM documentation

**Decisions made**:
- **Dual pipeline approach**: Validation in build catches issues early, release version is authoritative
- **SPDX 2.3 format**: Industry standard, meets NTIA requirements
- **Windows-only in build**: Only Windows builds all packages including net472
- **ubuntu-latest for release**: SBOM tool works on Linux, faster than Windows

**Files changed**:
- `.github/workflows/main.yml` - Added SBOM validation generation
