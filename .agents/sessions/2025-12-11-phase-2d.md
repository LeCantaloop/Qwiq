### CI Failure Fix (18:20 UTC)

**Issue**: GitHub Actions run #20142780429 failed with:

- "CodeQL analyses from advanced configurations cannot be processed when the default setup is enabled"
- Missing SARIF artifact upload
- SARIF files in wrong location (`/results` instead of `artifacts/CodeQL`)

**Root Cause**:

- GitHub repository has default CodeQL setup enabled, which conflicts with advanced configuration
- No artifact upload step for SARIF files
- SARIF output location not configured

**Solution Implemented**:

1. Set `upload: false` in CodeQL analyze step to prevent automatic upload (avoids conflict)
2. Added step to copy SARIF files from CodeQL temp location to `artifacts/CodeQL/`
3. Added artifact upload step for SARIF files with proper naming convention
4. Added comment explaining the upload is disabled pending default setup removal

**Files Changed**:

- `.github/workflows/main.yml`:
  - Modified "Perform CodeQL Analysis" step to disable upload
  - Added "Copy CodeQL SARIF to artifacts" step
  - Added "Upload CodeQL SARIF artifacts" step

**Next Steps for Repository Owner**:

- Disable default CodeQL setup in repository settings: Settings → Code security and analysis → Code scanning → CodeQL analysis → Disable
- After disabling, change `upload: false` to `upload: true` in the workflow
