### Pre-Flight Retrospective

**Issue**: Multiple attempts needed due to shell/SDK incompatibilities.

**Root Cause**: Bash shell doesn't handle MSBuild switches (`/m:1`, `/nodeReuse:false`) correctly with .NET 10 SDK. The CLI interprets them as separate arguments.

**Solution**: Use PowerShell for all .NET commands:

```powershell
pwsh -NoProfile -NonInteractive -Command "dotnet build Qwiq.sln ..."
```

**Additional issue**: File locking from previous builds. Use `git clean -fdx` before builds if locks persist.
